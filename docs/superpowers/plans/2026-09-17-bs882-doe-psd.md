> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a distinct BS 882:1992 / BS 812-103.1:1985 particle-size-distribution workflow for DOE/BRE 331, with a non-semilog plot, without changing IS 383 or ASTM C33 behavior.

**Architecture:** Extend the existing standard selector and generic PSD workflow, rather than create another PSD tab. Keep British grading data and checks separate; branch plot presentation explicitly by standard. Reuse the existing measured 600 µm handoff to DOE.

**Tech stack:** Python, existing Qt widgets, Matplotlib, pytest, existing JSON history storage. No new dependencies expected.

**Spec:** The verified BS 882:1992 grading tables (Tables 3–6) in the project-root Markdown extracts; BS 812-103.1 clauses 7/8/10; BS 812-105.1 flakiness limits; BRE 331 §1.2.5 (600 µm characterisation, no combined grading curves).

- BS plot uses a linear numerical sieve-size axis (app display policy, documented as such).
- Use the project virtual environment: `.venv/bin/python`; Qt tests need `QT_QPA_PLATFORM=offscreen`.

## 2. Decisions and scope

- Add selector entry **BS 882:1992 — DOE/BRE 331**, internal key `bs882`.
- Keep existing IS/ASTM sieve series, grading bands, smoothing, and logarithmic plots unchanged.
- Interpret the requested non-semilog graph as a **numerical linear sieve-size axis in mm**, with linear cumulative percentage passing from 0–100%. Label it explicitly. This is the requested application display policy, not a claim that BS 812 mandates numerical linear plotting. Its Figure 1 is a specimen recording chart.
- Keep fine and coarse PSD workflows. Do not introduce an all-in/combined-grading mix-design method: BRE §1.2.5 explicitly does not use combined grading curves. Table 5 is preserved in the reference for future use, not silently applied to a blend.
- BS 812-105.1 is a **flakiness test**, not a grading envelope. Record an optional independently measured flakiness index and assess the applicable BS 882 §4.2 limit. Do not infer it from retained sieve masses or build a new laboratory flakiness calculator in this change.
- Report limited, evidence-based outcomes such as “grading within selected limits.” Do not claim full BS 882 compliance from PSD alone.

## 3. Source requirements to implement

### Grading

**BS 882 Table 3:** use actual coarse sieve apertures **50, 37.5, 20, 14, 10, 5, 2.36 mm**. Provide graded references **40–5, 20–5, 14–5 mm**, and single-sized references **40, 20, 14, 10, 5 mm**. The 5 mm option must retain the precast-use note. Nominal 40 mm does not mean replacing the 37.5 mm sieve with a 40 mm sieve.

**BS 882 Table 4:** fine grading sieves **10, 5, 2.36, 1.18, 0.600, 0.300, 0.150 mm**. Provide Overall and additional **C/M/F** references. C/M/F selections combine the overall requirements with their additional limits; they are not IS Zones I–IV.

- Preserve all exact values from the verified Markdown tables.
- Omit dash cells from conformance checks; never manufacture 0–100% requirements.
- Sand classifications may overlap. Report all matching C/M/F gradings rather than force a single zone.
- Preserve the 150 µm crushed-rock exception and heavy-duty-floor restriction.
- A single sample cannot establish the §5.2.1 consecutive-sample condition. State that limitation.

### Test results and related checks

**BS 812-103.1 §§7–8:** support dry sieving and washing-plus-sieving. For washed samples use original dry mass M1 as denominator and include washed-out material M1−M2 with the dry pan fraction. Do not renormalize the washed residue to 100% or count washed fines twice.

**§10:** display/export cumulative passing to the nearest whole percent; retain unrounded calculation values internally. Capture sample identification and method. Missing provenance must remain “not provided,” not be assumed compliant.

**BS 882 Table 6:** offer the 75 µm sieve for a separate, material-specific fines check. This is not an extra control point to stretch the Table 3/4 grading envelope. Require appropriate washing evidence; otherwise mark the fines check not assessed.

**BS 882 §4.2 / BS 812-105.1:** optional measured FI, with maximum 50 for uncrushed gravel and 40 for crushed rock/crushed gravel. Unknown material or absent test → not assessed.
